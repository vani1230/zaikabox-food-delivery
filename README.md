Zaika Box - Multi-Role Food Delivery Ecosystem
Zaika Box is a comprehensive food delivery platform designed to bridge the gap between local shop owners, delivery partners, and customers. The app features a tripartite architecture with dedicated interfaces and functionalities for three distinct user roles.

🚀 Key Features
Role-Based Authentication: Integrated Google Firebase Auth for secure sign-in, allowing users to register as a Customer, Delivery Partner, or Shop Owner.

Real-Time Map Tracking: Live GPS integration using Google Maps API for customers to track their orders and delivery boys to navigate to destinations.

Secure Transactions: Integrated payment gateway for seamless digital transactions.

OTP Verification System: A two-factor verification process where an OTP is sent to ensure the order is handed over to the correct customer.

Dynamic Dashboard: * Shop Owners: Manage menus, track incoming orders, and view sales.

Delivery Boys: Accept/Reject orders and access navigation routes.

Users: Browse local shops, manage cart, and track live orders.

🛠 Tech Stack
Frontend: React

Backend: Node.js

Database: MOngoDB

Authentication: Google OAuth 2.0 

APIs: Google Maps SDK, Payment Gateway : Razorpay
